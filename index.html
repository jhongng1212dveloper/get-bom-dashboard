DOAS BOM Dashboard

GitHub Pages hosted bookmark installer · Package v0.11 · Dashboard engine v0.11

1. Install hosted bookmarklet

Press Ctrl+Shift+B to display Chrome's bookmarks bar. Drag the blue link below onto the bar (this installs the bookmark; do not click it on this installer page).

Generate DOAS Dashboard — Hosted

This bookmark always loads the current bookmarklet.js from your repository's GitHub Pages URL. No bookmark replacement is required when you deploy a new version.

2. Standalone fallback

Use this bookmark if DOAS blocks externally loaded JavaScript, or GitHub Pages is unavailable. It includes the v0.11 generator, but future updates require replacing this bookmark.

Generate DOAS Dashboard — Standalone

3. Publish to GitHub

Repository: jhongng1212dveloper/get-bom-dashboard

Upload all files from the ZIP to the repository root, making sure bookmarklet.js is present. Then enable GitHub Pages at Settings → Pages → Deploy from a branch → main / (root).

Verify bookmarklet.js is published at the GitHub Pages URL before using the hosted bookmark. Browser pop-up settings and the DOAS Content Security Policy can restrict automatic opening or hosted script execution. The generated report is also downloaded locally.

How to use

  1. Open DOAS in the same browser where you installed the bookmark.
  2. Click Generate DOAS Dashboard — Hosted. If necessary, it opens BOM Import and waits for the table.
  3. The bookmarklet requests a download and tries to open the same generated dashboard in a new tab. If blocked, use the Open dashboard link on the DOAS page. Module 7000 is excluded by default but can be toggled on.

Only table rows loaded in the DOAS page are extracted. The tool downloads the report locally and does not send BOM records to GitHub. The hosted bookmark executes public JavaScript from your repository; review changes before publishing.
